# 数字经络图谱 — 2D 交互设计方案

## 核心概念

不是 3D 的"降维版"，而是一个完全不同的体验——数字化的古典经络图，像翻阅一本精美的中医古籍。

## 视觉风格

### 白描工笔人体
不是写实照片，而是传统医学插图的线描风格，用干净的墨线勾勒人体轮廓，配以淡墨晕染表示肌肉起伏。参考《针灸铜人腧穴图经》和《十四经发挥》里的人体图。

### 宣纸底
背景有微妙的纸纹质感，不是纯白平面。

### 朱砂点穴
穴位是小的朱砂红圆点，点击后展开成一个墨韵圆圈。

### 墨笔经络线
经络用有粗细变化的毛笔线条绘制，不是均匀的直线，有书法笔锋的感觉。选中时有墨迹从起点流向终点的动画，像挥毫泼墨。

## 交互体验

### 三视图切换
正面 · 背面 · 侧面，切换时用水墨晕散过渡（上一个视角的墨迹化开消散，新视角的墨迹重新凝聚出现）。

### 经络选择
选一条经络，它的路径像有人在纸上现场画出来一样，一笔一笔地显现，穴位依次点亮。

### 穴位详情
点击穴位后，信息不是弹出一个现代感的卡片，而是像古籍批注一样出现在旁边，竖排文字，用线连接到穴位。

### 滚动浏览
整体可以像卷轴一样纵向滚动浏览全身，或者分"头颈"、"胸腹"、"上肢"、"下肢"几个区域。

## 技术方案

- **SVG** 做人体线描图（矢量，缩放清晰，可以做笔画动画）
- 用现有 3D 数据的正交投影生成穴位 2D 坐标
- Canvas 2D 或 SVG filter 做墨迹动画效果
- CSS 做宣纸纹理和古籍排版

## 数据复用

现有数据文件可直接复用：
- `data/points.json` — 穴位信息（名称、编码、定位、主治等）
- `data/meridians.json` — 经络信息
- `data/unity_points.json` — 3D 坐标，需正交投影为 2D
- `data/meridian_paths.json` — 经络路径点，投影后作为 2D 曲线
- `data/extra_points.json` — 奇穴数据
